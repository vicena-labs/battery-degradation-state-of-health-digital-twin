# Agent playbook

1. Inspect the package, schemas, dataset provenance, and executed notebook outputs.
2. Reproduce tests and baseline metrics without editing the model.
3. State the requested scientific objective and acceptance criteria.
4. Validate new data and stop on missing units, cell identity, chemistry, or test conditions.
5. Create a new case study. Do not overwrite reference data.
6. Split by physical cell, campaign, or site before fitting.
7. Compare with a simple baseline and report residuals and uncertainty.
8. Update tests, notebooks, one pager, model card, changelog, and citations.
9. Run the complete workflow and inspect conformal coverage, bootstrap intervals, pack bounds, and Pareto labels.
10. Never treat Level 0 pack or policy outputs as measured performance.
