# Getting started

Part of the [Vicena Research Twins collection](https://vicena.ai).

Install the package, run `python examples/quickstart.py`, then run `python scripts/run_validation.py`. The first command exercises the synthetic Level 0 model. The second uses measured calendar-aging data and writes group-held-out predictions. Open the two notebooks for interactive plots and printed checks. Input current is positive on discharge. Time is seconds, capacity is Ah, voltage is V, temperature is degC, and SOH is measured discharge capacity divided by the first capacity in the same cell-condition trajectory.
