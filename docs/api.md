# API reference

Part of the [Vicena Research Twins collection](https://vicena.ai).

- `simulate_profile`: Level 0 single-cell electro-thermal time history.
- `synthetic_aging`: Level 0 scenario capacity fade and resistance growth.
- `simulate_pack`: Level 0 pack aggregation and cell-to-cell variability.
- `load_calendar_ageing`: measured data normalization and SOH derivation.
- `fit_evaluate`: group-held-out Level 1 regression and baseline metrics.
- `conformal_evaluate`: group-separated split-conformal intervals.
- `grouped_bootstrap_metrics`: cell-condition grouped MAE uncertainty.
- `stress_sensitivity`: synthetic stress-factor grid.
- `pareto_policies`: throughput versus synthetic SOH nondominated policies.
- `validate_csv`: deterministic uploaded-data checks.
